# Vexi FIX10 — предрелиз и порядок проверки

Это тестовая сборка, не стабильный релиз. Подключён локальный диалог на ограниченном наборе общих тем и продолжений. Произвольный разговор на любые темы пока не реализован. Настройка нового диалога по умолчанию выключена: реальные проверки Qwen выявили неестественные формулировки и повторы. Качество генерации НЕ получило PASS.

## Установка
Распакуйте ZIP целиком, затем запустите INSTALL_VEXI.cmd. Для уже обновлённой C:\Vexi повторная установка не нужна.
Установщик создаёт полную резервную папку перед заменой, сохраняет настройки и данные. Не закрывайте окно до результата.
VOICE_STARTUP_PENDING означает ожидание загрузки, а не готовность. Даже MICROPHONE_READY не подтверждает успешный разговор.
Первый ответ модели после холодного старта может занять до минуты; в измерении было 44.77 секунды. Повторные ответы в синтетической проверке занимали 0.2–0.92 секунды, без времени микрофона и озвучивания.

## Сначала — без музыки и игры
1. Скажите «Векси, какая версия?». В ответе должен быть FIX10. Проверьте, что есть текст и голос.
2. «Векси, привет», затем «хмм… мм… ии…». На междометия — тишина.
3. Откройте Настройки → Ассистент → Разговор. Включите «Локальный диалог на общие темы (предрелиз)» и продолжение без повторного обращения. Сохраните.
4. «Векси, предложи два варианта отдыха дома». Должны прозвучать два варианта.
5. Без имени: «второй подробнее». Ответ должен развивать именно второй вариант. Если заменяет его другим занятием — FAIL, даже если ответ звучит уверенно.
6. «Без компьютера». Ответ должен учитывать ограничение. Дословное повторение без адаптации или странные фразы отмечайте FAIL качества.
7. «Векси, почему небо голубое», затем «объясни проще». Проверяется смена темы и связное объяснение. Эта небольшая модель может ошибаться в фактах; успешный сетевой ответ не означает правильность содержания.
8. «Повтори». Должен повториться последний ответ.
9. «Стоп». Озвучивание прекращается; «подробнее» без имени после этого не должно начинать разговор. Затем «Векси, продолжим разговор» — возврат к прежней теме.
10. Выждите более 90 секунд после ответа. «Подробнее» без имени — тишина. «Векси, объясни проще» — тема ещё доступна.
11. «Векси, забудь разговор». Затем «Векси, подробнее»: прежний ответ не должен восстанавливаться. История также не переживает перезапуск.
12. «Векси, открой личные документы». Должен сработать запрет существующего маршрута; модель не должна заявлять, что открыла файлы.
13. Отключите продолжение без имени. Уточнение без обращения должно игнорироваться; с «Векси» — приниматься.
14. Выключите экспериментальный диалог и сохраните. Память нового диалога очищается на следующей обработанной реплике, а готовые ответы FIX9 остаются.

## Затем — музыка и STALKER
Включите обычную для вас громкость. Повторите пункты 2, 4, 5 и 9.
Отдельно оставьте Vexi на 3–5 минут без обращения. Любой ответ на фон отметьте как ложную активацию.
Слова «подробнее», «почему», «стоп» из игры могут совпасть с разрешёнными продолжениями. Различение говорящего и аудиоисточника не реализовано; нельзя обещать нулевые ложные срабатывания.
При ложных активациях выключите «Продолжать разговор без повторного обращения» — для следующего запроса понадобится имя.
Перебивание во время TTS проверяется отдельно. Во время ожидания модели голосовое распознавание не работает параллельно: отмена доступна через выключение слушания/выход, не обещаем голосовой «стоп» на стадии «Думаю».

## Как записать результат
Для каждого пункта: номер, фраза, текст ответа или краткое описание ошибки, была ли музыка/игра, примерное ожидание. Не присылайте пароли и личные документы.
PASS ставьте только после реального повторения пункта. Сейчас microphone field = NOT_RUN.

## Откат
Сначала закройте Vexi через значок в трее. Запустите RESTORE_PREVIOUS.cmd из этой распакованной сборки. После сообщения восстановления запустите обычный ярлык Vexi.
Убедитесь, что снова работает приветствие/голос и вернулась предыдущая сборка.
Не удаляйте резервную папку, пока не завершены проверки.

## Границы предрелиза
Поддержанные начала: «расскажи о космосе/музыке/кино/книгах/играх/сталкере/роботах», «почему небо голубое», «объясни как работает искусственный интеллект», «предложи два/три варианта отдыха дома», «чем заняться вечером дома».
Продолжения: «подробнее», «объясни проще», «короче», «приведи пример», «второй подробнее», «без компьютера», «подешевле», «другие варианты», «продолжим разговор».
Полный список грамматик находится в local_dialogue.py; неподдержанная формулировка не отправляется в модель. Это сознательно ограниченный первый этап, а не свободная классификация произвольных личных данных.
Модель работает через 127.0.0.1:11434, без инструментов, владельческой памяти, файлов и облачного fallback. Сервер Ollama должен быть запущен, модель уже установлена. Автозагрузка модели не выполняется.
Тексты принятых общих реплик хранятся только в оперативном контексте приложения. Приложение не пишет их в обычные логи; это не гарантия очистки ОС swap или внутренних буферов Ollama.
Roborock Q7 L5+ в этот пакет не включён. Зафиксирован отдельный маршрут проверки через Home Assistant; обнаружение конкретного устройства ещё не выполнялось.
