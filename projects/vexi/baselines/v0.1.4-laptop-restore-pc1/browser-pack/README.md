Vivaldi adaptation of the supplied Vexi Chrome Browser Pack 0.1.2.
Run INSTALL_BROWSER_PACK.bat, then open vivaldi://extensions, enable Developer mode and Load unpacked:
%LOCALAPPDATA%\VexiBrowserPacks\Vivaldi\extension
Select Vivaldi in Vexi browser settings.
Local port: 8767. Authentication is generated locally; no token is included.
Static checks only; browser connection and voice control require a field test.
