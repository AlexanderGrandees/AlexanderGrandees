# Vexi: текущая рабочая основа — 0.1.4 laptop-restore-pc1

Зафиксировано 2026-09-23. Канал local-restoration, исходная версия с ноутбука: 0.1.4 public-preview / media-context-natural-control.

Решение владельца: «все супер … идём дальше от неё». Новая работа начинается с этой основы. FIX10a и A+B+C сохраняются как экспериментальная ветка, не как рабочая замена.

## Что сохранено
Полный комплект модулей восстановления совпадает с установленными файлами ПК на момент фиксации. Старый Router снова вызывается голосовым циклом; продолжение разговора работает в прежнем временном окне. Сохранены RAM-only запись микрофона, фильтрация междометий, быстрый ответ на известные разговорные вопросы, pythonw bootstrap. Голосовое перебивание отключено из-за ложных срабатываний на шум. Браузер — Vivaldi.

## Evidence и ограничения
- Синтаксис подготовленных Python-модулей проверен.
- Штатный regression_tests_v014.py завершился успешно. Это набор проверок, не полная проверка действий голосом.
- test_restore_voice.py: один сценарный тест с подменёнными устройствами подтвердил обращение, DROP междометий, ответ на «как дела» без LLM, передачу команд Vivaldi/YouTube/пауза старому Actions.
- Живой запуск: MICROPHONE_READY, launch_id laptop-restore-pc1-20260923.
- Пользователь после запуска подтвердил «все супер». Отдельного протокола каждого сценария нет; не приписывать индивидуальный PASS всем командам.
- Последняя автоматическая проверка Browser Pack показывала extension_connected=false. Более позднее общее подтверждение пользователя не заменяет точечную проверку связи.
- Guest/owner-модель A+B+C и удержание задач до явного завершения НЕ сертифицированы для восстановленной 0.1.4. Это рабочая основа, не выпуск безопасного гостевого агента и не стабильная 0.1.5.
- Локальная модель, задержки и прерывание голосом требуют отдельной доработки.

## Как продолжать
Не подменять Router незавершённой архитектурой. Разделять свободное понимание речи и проверяемое исполнение. Для каждой правки: backup -> coherent replacement -> syntax/regression -> launch -> field test -> rollback. Перед продвижением проверить живые «как дела», открытие Vivaldi и YouTube, выбор/паузу/продолжение видео, продолжение без имени, тишину на шум. Не заявлять успех действия без evidence.

## Состав и воспроизведение
Это снимок исходников, НЕ готовый установщик. .venv, модели, личные настройки/память, журналы и ключи исключены. config.example.json содержит только нейтральные настройки; при новой установке создать config.json из примера и настроить локальные зависимости. requirements_v014.txt задаёт зависимости исходной версии, но чистая установка этого снимка отдельно не проверена. Browser Pack создаёт ключ локально; загрузить установленную extension через «Загрузить распакованным» и проверить соединение.

## Откат на этом ПК
Предыдущая сборка: C:\Vexi-backup-before-laptop-restore-20260923. Исходная копия ноутбука оставлена без изменения. Текущий ярлык запускает C:\Vexi\vexi.py через установленный pythonw с запросом администратора. Не копировать личные настройки и ключи из одной машины в публичный репозиторий.
