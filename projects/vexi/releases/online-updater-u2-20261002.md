# Vexi U2 — подписанные онлайн-обновления, 2026-10-02

Реализован отдельный русскоязычный обновлятор U2 для получения пакетов из GitHub Releases. Аренда сервера, белый IP и GitHub-токены у получателей не требуются. Публичный канал `vexi-alpha` пока не содержит подписанного выпуска: живой HTTPS-запрос вернул NO_RELEASE. Готовность клиента не означает, что обновление уже опубликовано.

## Что реализовано
- Явные действия: проверить → скачать → установить → откатить; без фоновой автоустановки и повышения прав.
- Подпись Ed25519 с закреплённым ключом bootstrap. Закрытый ключ издателя хранится отдельно, защищён DPAPI, не включён в репозиторий и архив.
- Подписаны канал, репозиторий, версия, совместимые исходные сборки, последовательный номер, URL, размер, SHA-256 и срок действия до 31 дня.
- Ограниченные HTTPS-загрузки с допустимыми доменами перенаправления GitHub, тайм-аутами и проверкой полного размера.
- Отказ при чужой подписи, устаревшем номере, замене содержимого известного номера, просроченной метаинформации или несовместимой сборке.
- Строгий состав ZIP; пользовательские файлы, обход путей, ссылки и внешний updater.py не допускаются.
- Перед установкой подпись/ZIP проверяются повторно, распаковка выполняется заново. Изменённые файлы распакованного кэша не используются.
- Установка через транзакционный U1: резервная копия, проверка зависимостей, замена, проверка результата, откат. Удаление браузерного шаблона теперь тоже блокируется как изменение протокола.
- Кэш сетевых загрузок находится в пользовательском LocalAppData. Проверка сети не требует доступа к защищённой блокировке установки.

## Проверки
- 19 тестов доставки/подписи/ZIP/GUI-протокола — PASS.
- 18 тестов транзакционного обновлятора — PASS.
- Реальный native payload Protected P2 → P3: подписанное скачивание через локальный HTTP-стенд, проверки зависимостей и native selftest — PASS.
- Откат при выключенном HTTP-стенде — PASS; 33 исходных файла восстановлены, синтетические настройки/диалоги/модели/ключи сохранены.
- Комплектная библиотека проверки подписи работает с существующим Python без установки пакетов в окружение Векси — PASS.
- Создание окна в PowerShell 5.1 без показа — PASS. Интерактивное нажатие кнопок и голосовой тест ноутбука — NOT_RUN.
- Живой запрос GitHub HTTPS — NO_RELEASE, ожидаемо для неопубликованного канала.
- Рабочая исходная сборка ПК local-p4-mapping — несовместимый пакет отклонён. Работающая Векси не заменялась и не перезапускалась.

## Доставка и ограничения
На рабочем столе в «Векси / 02 Обновление»: папка «Онлайн-обновление U2», русский ярлык и ZIP.
SHA-256 bootstrap ZIP: `b12364baf3615ab359cfb7241fce891bb546d7b69039a3376e6b6f55c3179abf`.
Размер ZIP: 3 975 957 байт.
Поддерживается формат protected-core-v1. Доработанная исходная версия ПК требует отдельного совместимого пакета/миграции. Изменение зависимостей или браузерного протокола не форсируется.
Пробный подписанный пакет P3 подготовлен для проверки механизма и НЕ опубликован как новая актуальная версия. Перед публичной доставкой нужен выбранный совместимый кандидат и его полевые проверки.

Не реализованы: автоматическая ротация ключей, полноценные метаданные TUF, самоперезапуск Векси, фоновое расписание проверки. Никакие модельные файлы, диалоги, ключи браузеров или закрытые исходники ядра не публикуются.
