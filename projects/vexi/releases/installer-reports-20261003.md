# Векси: исправление проверки зависимостей и отчёты установки — 2026-10-03

Пакет `protected-p4-1-install-reports` заменяет `protected-p4-1-ui-updates`. Базовая версия ядра остаётся 0.1.4; это не выпуск завершённой v0.1.5. Native core Protected P4 не изменён.

## Исправления

- Проверка закреплённых зависимостей использует правила PEP 440: допустимый локальный вариант, например torch 2.14.0+cpu при требовании ==2.14.0, больше не отклоняется строковым сравнением. Остальные несовместимые версии по-прежнему блокируются.
- При несовпадении записываются найденная/требуемая версии; сохраняется вывод pip.
- Каждая попытка установки получает отдельную папку на системном Desktop: Векси / 06 Журналы / Установка / дата-время-идентификатор. Поддерживается перенаправленный Desktop.
- Путь отчёта сохраняется через UAC-переход в том же аккаунте. Runtime запускается обычным пользователем.
- После успеха/ошибки создаются ОТЧЁТ.txt и Vexi-install-report.zip. В ZIP только установочные логи; конфигурация, диалоги, ключи и install-plan исключены.
- Добавлена кнопка «Открыть журнал» и указатель «Последняя установка.txt».
- Блокировка параллельной установки сохранена.

В присланном журнале вторая попытка была блокирована, а первая завершилась на проверке torch до замены установки. Ошибка совместимых локальных версий воспроизведена отдельно; точная установленная версия torch на целевом ноутбуке из старого журнала неизвестна.

## Проверки

- 10 регрессионных тестов отчётов/версий/блокировки — PASS.
- 17 тестов дистрибутива — PASS.
- Реальная изолированная установка, native preflight до/после, backup, сохранение голоса/настроек/синтетических журналов и 8 обычных ярлыков — PASS.
- Синтаксис Python/8 PowerShell-файлов, создание и визуальная проверка скрыто отрисованного установщика — PASS.
- CRC и SHA-256 содержимого итогового ZIP — PASS.
- Зависимости в изолированной установке переиспользованы из тестового окружения. Полная чистая загрузка зависимостей, физический ноутбук, микрофон/колонки и реальные браузеры после установки — NOT_RUN.
- Живой GitHub check — NO_RELEASE. Публичный подписанный выпуск этим изменением не опубликован.
- Предыдущие тесты Tk и подписанного обновления/офлайн-отката относятся к предыдущей UI-сборке; соответствующие файлы не изменены и сверены по хэшу.
