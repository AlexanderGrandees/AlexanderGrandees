# Vexi 0.1.5.dev4 — FIX8, тестовая сборка

FIX8 исправляет загрузку голосовой модели при запуске без консоли, проверку готовности
дочернего процесса Python и ожидание установщиком завершения самой Vexi.

Распакуйте ZIP целиком. Запустите INSTALL_VEXI.cmd и разрешите запрос Windows.
Нужны Python 3.11 x64, интернет для зависимостей и первого скачивания моделей,
свободное место для среды Python, моделей и полной резервной копии.
Установка по умолчанию: C:\Vexi. Пакет поддерживает отсутствие этой папки.

Сначала проверяются контрольные суммы, затем собирается отдельная staging-папка.
Существующая C:\Vexi сохраняется рядом как Vexi.backup-дата. Код заменяется целиком.
Настройки, модели и рабочие документы переносятся в staging. При ошибке после
переключения выполняется откат. Для ручного возврата: RESTORE_PREVIOUS.cmd.
Старая C:\Jarvis не удаляется и не считается автоматически Vexi 0.1.4.

Журнал: %LOCALAPPDATA%\VexiInstaller\install-latest.log.
Если установка не удалась, сохраните этот журнал. Системные зависимости и модели
не включены в ZIP. Python не скачивается автоматически. Если установка прервана
во время переключения папок, сначала используйте RESTORE_PREVIOUS.cmd.

Это DEVELOPMENT, не готовый стабильный релиз. В сборке есть A+B+C, локальный
жизненный цикл документов, DOCX и диагностика. Голосовой вход пока использует
ограниченный безопасный набор команд: полная совместимость со старым Router,
свободный LLM-диалог и подтверждение владельца голосом не завершены.
Контекст задачи сохраняется, но продолжение через микрофон требует активации.
Вкладка Diagnostics находится в настройках. FAST/CORE/DOCUMENT/REGRESSION —
синтетические проверки; они не подтверждают работу реального микрофона.

VOICE_STARTUP_PENDING означает, что модели ещё не подтвердили готовность.
VOICE_READY означает открытие микрофона после загрузки компонентов, но не успешный
полевой тест. После запуска отдельно проверьте активацию, ответ голосом, фоновую
речь без записи текста, гостевой запрет защищённых действий и восстановление задачи.
Не присваивайте этим проверкам PASS без фактического результата.
