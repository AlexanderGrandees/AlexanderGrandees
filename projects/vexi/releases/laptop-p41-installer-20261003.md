# Vexi Alpha P4.1 — ноутбук, автопроверки и центр управления

Собран установочный пакет Alpha P4.1 для ноутбука. Сборка protected-p4-1-online-center, версия ядра 0.1.4. Это продолжение защищённого P4, не завершённая v0.1.5. Рабочая исходная Векси на основном ПК не заменялась и не перезапускалась.

## Состав
- Неизменённый бинарный core из protected-p4-final: SHA-256 совпадает. Прежняя голосовая логика сохранена.
- Русский центр Векси: запуск, настройки, микрофон/голос, браузеры, журналы, отчёт и обновления.
- Новая иконка с вариантами пяти состояний; обновлённый тёмный установщик, центр и окно обновлений.
- Пять браузерных модулей: Vivaldi, Chrome, Edge, Brave, Opera.
- Проверка U2 при запуске и каждые 6 часов, пока работает ассистент; первый запрос через 20 секунд. После ошибки повтор не раньше часа. Проверки отключаются в центре. Установка только явно, с подтверждением остановки.
- Пакет проверяет Python/зависимости, предлагает подготовить модели речи и выбрать диск. Ollama и языковая модель устанавливаются отдельно по инструкции.
- Обычный запуск без администратора. UAC только при необходимости записи в выбранную защищённую папку.
- Голос, настройка диалогов и журналы сохраняются при обновлении. Финальный снимок данных после остановки учитывает удаления, чтобы не возвращать удалённые файлы.
- Исправлен воспроизведённый сбой установки: браузерные модули теперь настраиваются через проверенное окружение Векси, а не системный Python без cryptography.

## Проверки и evidence
17 проверок дистрибутива и 37 проверок комплектного U2/U1 прошли (54 суммарно).
Настоящий установщик прошёл обновление изолированной копии: native selftest и импорты до/после замены, сохранение голоса eugene, настройки логирования, синтетических диалогов, резервная копия, восемь ярлыков без RUNAS.
Подписанное тестовое обновление через локальный HTTP-стенд и откат после отключения стенда прошли; восстановлены все 43 исходных файла.
Конструирование трёх окон PowerShell 5.1 и визуальная проверка отрисованных окон пройдены. Интеграция иконок/пункта меню проверена с подменённым системным треем, микрофон не включался.
Итоговый архив проверен по CRC и SHA-256 каждого файла; исполняемые файлы совпадают с проверенным кандидатом r4.

NOT_RUN: установка зависимостей с нуля на чистом физическом ПК, интерактивные внешние запуски из GUI, другой DPI, микрофон/колонки и браузерный полевой тест ноутбука. Изолированная установка использовала уже доступные библиотеки. Полный отчёт — TEST_EVIDENCE.json в пакете.

## Доставка
На рабочем столе: Векси / 03 Установка / Векси P4.1 — установщик для ноутбука.zip.
Размер: 5 638 654 байта; 225 файлов.
SHA-256: 0e8df948317c4657dee814bf9ae47ae8755edc1afcbef965d3c6b0f3d994a1dc.
Распаковать полностью, открыть УСТАНОВИТЬ.cmd, выбрать существующую папку Векси. Расширения подключить/перезагрузить по BROWSERS.html. Порядок голосового и браузерного теста — README_RU.md.
Закрытые ключи, исходники ядра, пользовательские настройки/диалоги и токены в архив не включены.

## Канал обновлений и дальнейшая работа
Живой анонимный HTTPS-запрос GitHub вернул NO_RELEASE: подписанного публичного выпуска ещё нет. Проверка канала реализована; публикация обновления этим не подменяется.
Защищённые выпуски используют pinned Ed25519, совместимость, SHA-256, ограничения ZIP, backup и rollback. Bootstrap обновляется полным установщиком; изменения браузерного протокола требуют миграции.
Следующий шаг: полевой тест ноутбука, затем подписанный совместимый выпуск через GitHub Releases. Экспериментальный Mystic Light в этот пакет не включён.
Реализация и тесты сохранены локально в projects/vexi/installer-alpha/desktop-p41; код ядра не перекомпилировался.
