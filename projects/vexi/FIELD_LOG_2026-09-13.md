## 17:17–17:28 — Browser Pack v0.1.0 installed but Core reported not installed
Pack files and extension existed physically, yet Core status returned:
```json
{
  "installed": false,
  "connected": false,
  "detail": "browser_pack_not_installed"
}
```

Manifest byte inspection showed:
```text
FIRST BYTES: EF BB BF
```
Root cause: Windows PowerShell 5.1 wrote the plugin manifest as UTF-8 with BOM while Core parsed it as plain `utf-8` and silently skipped the JSON error.

Outcome: Browser Pack v0.1.1 switched manifest writing to UTF-8 without BOM, added registration self-test, diagnostics, and visible bridge warnings.
