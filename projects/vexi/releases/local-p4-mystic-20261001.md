# Vexi: локальное обновление и модуль Mystic Light — 2026-10-01

## Фактический статус
- На основном ПК установлен local-p4-mapping поверх рабочей ветки laptop-restore-pc1-interruption2-sensitive1. Это локальная сборка 0.1.4, не релиз 0.1.5 и не защищённый установщик P4.
- Сохранены основной голосовой цикл, распознавание, настройки и conversation-модуль. Перед заменой сделана резервная копия; совпадение SHA-256 восьми сохраняемых файлов проверено.
- 1 октября диагностический запуск достиг MICROPHONE_READY с новым launch_id. Голосовой полевой тест пользователем после этого обновления ещё не подтверждён.
- Модуль Mystic Light установлен отдельными файлами для следующего запуска. Во время фильма пользователя Векси не перезапускалась, окна и подсветка больше не менялись.
- Реальное управление Mystic Light НЕ подтверждено: официальный SDK 1.0.0.08 возвращает 0 на Initialize, но GetDeviceInfo зависает. Изолированный worker ограничен 12 секундами; статус TIMEOUT. Принудительное повышение прав не используется.
- Последняя проверка Vivaldi: extension_connected=false. Файлы расширения обновлены с сохранением локальных ключей; живой тест свежего снимка страницы не завершён. Это не PASS.

## Изменения P4
Поиск приложений через Windows App Paths и ярлыки, обновление карты без сохранения устаревших записей; неоднозначные имена требуют уточнения. Обычное «открой» сначала выбирает существующее окно. «Открой новое окно» — отдельная команда, реализованная для браузера; для произвольных приложений новое окно не имитируется повторным запуском.
Чтение браузера запрашивает текущий снимок с идентификаторами запроса, вкладки и документа. Старый снимок не используется при ошибке. Поля формы описываются без чтения введённых значений. Доступ к окнам с более высокими правами блокируется.

## Команды Mystic Light
Область по выбору владельца — весь ПК: все зоны, которые фактически вернул SDK.
- «Проверь подсветку» — текущие зоны, эффекты и цвет.
- «Какие эффекты подсветки?» — пересечение эффектов всех зон.
- «Выключи подсветку».
- «Включи подсветку» — постоянный свет; чёрный цвет заменяется белым, нулевая яркость — доступным максимумом.
- «Сделай подсветку синей» — также красная, зелёная, белая, фиолетовая, жёлтая, голубая, оранжевая.
- «Сделай подсветку #FF8800» — точный RGB.
- «Поставь эффект радуга на подсветке»; дыхание, постоянный, мигание — только если соответствующее название реально присутствует среди эффектов. Можно назвать точное имя эффекта SDK.
- «Поставь яркость подсветки 50 процентов».
- «Поставь скорость подсветки 25 процентов».

Это контракт реализованного модуля, а не утверждение совместимости всех устройств. Перед записью проверяются все зоны. Если хоть одна зона не поддерживает режим, записи не начинаются. После записи результат считывается повторно для каждой зоны; при ошибке предпринимается откат. При тайм-ауте результат и откат не считаются подтверждёнными. Отрицания, рассказы и условные фразы не запускают действие. Игровая синхронизация, музыка, профили MSI и произвольное управление вентиляторами не входят в данный SDK-адаптер.

## Evidence
- P4: синтаксис 82 Python-файлов; импорт с установленными зависимостями; 10 mapping-тестов; 13 window/access-тестов.
- Browser: Node fixtures — свежий запрос, гонка вкладки, неоднозначность, новое окно, метаданные полей без значений, блокировка устаревшего документа.
- Mystic: 10 изолированных тестов — отрицания, команды, все зоны, preflight до записи, откат, проценты, тайм-аут, неизвестный эффект, включение, повторное чтение.
- После интеграции Mystic повторно прошли 10 mapping-тестов.
- Подпись официального SDK проверена: Valid, MICRO-STAR INTERNATIONAL CO., LTD.
- SDK live read: TIMEOUT. Живое переключение света не проводилось.
- Полный A+B+C, owner verification, документы и гостевые ограничения этим обновлением не сертифицированы.

## Продолжение и выпуск
1. Когда ПК свободен: обычный перезапуск Векси, проверить версию и микрофон.
2. Восстановить соединение Vivaldi без переустановки и потери токена; проверить свежесть на отдельной безопасной странице.
3. Устранить совместимость GetDeviceInfo с установленным MSI Center без автоматического admin. До этого не объявлять Mystic рабочим.
4. Только затем проверить цвет/выключение/включение/эффекты/яркость/скорость с реальным визуальным подтверждением и возвратом исходной подсветки.
5. Не включать экспериментальный модуль в установщик другого ПК до этих проверок.
